# Ulalam
(Cookify / LutongBahay)
*Discover, plan, and master Filipino cooking.*

*what is the problem?*
- Struggling with deciding what to cook and which to cook.

*What is?*
- An application that keeps you collection of ulam that you can cook and search ulam using ingredients you already have as well as a guide on how to cook ulams and recording those ulams for you to know what you have already cooked in the past 7 days.

*Why build it?*
- To help in searching what ulams can be cooked using the readily available ingredients and decide which of these ulams to cook.
